# Scroll-Driven Hero Section Animation

## Assignment
Recreate a premium hero section with:
- Letter-spaced headline
- Statistics / impact metrics
- Smooth page-load reveal
- Scroll-linked visual animation
- Responsive layout
- Transform-based animation for better performance

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- GSAP + ScrollTrigger

## Files
- `index.html` — page structure and SVG hero visual
- `style.css` — responsive styling and animations
- `script.js` — GSAP intro and scroll-driven animation

## Run Locally
1. Download/extract the project.
2. Open `index.html` in a browser.
3. Internet is required for the Google Font and GSAP CDN.

## GitHub Pages Submission
1. Create a GitHub repository, for example:
   `scroll-driven-hero-animation`
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save and wait for deployment.
7. Submit:
   - Live webpage URL
   - GitHub repository URL

## Example submission format
Live Webpage:
https://YOUR-USERNAME.github.io/scroll-driven-hero-animation/

GitHub Repository:
https://github.com/YOUR-USERNAME/scroll-driven-hero-animation

## Note
The main car visual is an inline SVG, so no image file is required. The animation is tied to scroll progress and uses GSAP ScrollTrigger with `scrub`.
